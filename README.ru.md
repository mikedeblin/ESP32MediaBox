# ESP32-S3 Audio Player

[English](README.md) | **Русский**

Портативный MP3-плеер на ESP32-S3. Играет музыку с microSD или по сети с медиасервера DLNA/UPnP
(проверено с Synology Audio Station). Цветной TFT 1.8" с четырьмя режимами экрана, маленький
OLED для статуса, энкодер с кольцом из 16 светодиодов и четыре кнопки, а на выходе компрессор
и лимитер, которые не дают перегрузить ЦАП.

![ESP32-S3 Audio Player](docs/player.jpg)

## Возможности

- **Два источника.** microSD (браузер по папкам, плейлист = папка) и DLNA (просмотр
  ContentDirectory сервера, воспроизведение потоком по HTTP).
- **Четыре экрана на TFT.** Карточка трека с маленькой обложкой, сегментные VU-полосы с
  удержанием пика, стрелочные VU-индикаторы L/R с баллистикой около 300 мс и обложка на весь экран.
- **Обложки.** JPEG из кадра ID3 `APIC` (SD) или из `albumArtURI` в DLNA (сеть).
- **Теги.** ID3v2.3/2.4 в UTF-16, UTF-8, Latin-1 и Windows-1251, кириллица отображается.
- **Сглаженные шрифты.** PT Sans (латиница и кириллица), сгенерированы в формат VLW.
- **Сетевой буфер.** Кольцевой буфер 256 КБ в PSRAM, его заполняет отдельная задача, поэтому
  короткие провалы WiFi не слышны.
- **Обработка выхода.** Громкость в dB, затем компрессор в духе ReaComp (RMS-детектор, по
  умолчанию ∞:1) и лимитер с упреждением. Оба стоят после громкости и работают только тогда,
  когда на выходе действительно громко.
- **OLED со статусом.** Крупная иконка ▶ / ❚❚ / ■ с надписью PLAY / PAUSE / STOP и ↻1, когда
  включён повтор трека.
- **Кольцо светодиодов вокруг энкодера.** 16 светодиодов через MCP23017: громкость на
  светодиодах 1–15, красный 16-й — пауза или mute, в браузере — позиция курсора.
- **Запоминает состояние.** Громкость, повтор, экран, последний источник, папка и трек хранятся
  в NVS и восстанавливаются при включении.

## Железо

| Компонент | Примечание |
|---|---|
| ESP32-S3-DevKitC, **N16R8** (16 МБ flash, 8 МБ OPI PSRAM) | PSRAM обязательна |
| Модуль ЦАП PCM5102A (фиолетовая плата «GY») | I²S, аппаратный режим |
| ST7735S 1.8" TFT, 128×160, SPI | красный модуль, его слот SD не используется |
| SSD1306 OLED 0.91", 128×32, I²C | дисплей статуса |
| Модуль microSD, SPI | карта FAT32 |
| Энкодер с кнопкой и кольцом из 16 светодиодов | кольцо — матрица 4×4: 4 катода + 4 анода |
| Расширитель GPIO MCP23017 по I²C (модуль CJMCU) | управляет кольцом |
| 4 тактовые кнопки | на GND |
| Модуль заряда IP5306 + LiPo | питание 5 В |

### Подключение

| Функция | GPIO ESP32-S3 |
|---|---|
| TFT (FSPI) | SCK 18, MOSI 9, CS 10, DC 13, RST 4, подсветка 2 |
| microSD (SPI3, отдельная шина) | SCK 40, MISO 42, MOSI 41, CS 5 |
| PCM5102A (I²S) | BCK 14, LRCK 12, DIN 11, XSMT 39 |
| OLED + MCP23017 (общая шина I²C) | SDA 21, SCL 47 |
| Энкодер | A 15, B 16, SW 17 |
| Кнопки | PREV 1, NEXT 6, PLAY 7, MODE 8 |

Кнопки и кнопка энкодера замыкают GPIO на GND, используются внутренние подтяжки.

**Модуль MCP23017.** VCC на 3.3 В (не 5 В), A0/A1/A2 на GND (адрес 0x20), RESET на 3.3 В.
NC/CS, NC/SO и выходы прерываний ITA/ITB не подключать. Подтяжек I²C на модуле OLED хватает
на всю шину. Кольцо подключается к порту A: в этой сборке аноды кольца (его пины 5–8) на
GPA0–3, катоды (пины 1–4) на GPA4–7. При другой распайке поменяй `RING_ANODE_BIT` /
`RING_CATH_BIT`. Каждый катод тянет сразу до четырёх светодиодов, поэтому ток светодиода
держи около 5 мА (220–330 Ом в линиях анодов, если на кольце нет своих резисторов).

**Не использовать** на DevKitC N16R8: GPIO 0, 3, 45, 46 (strapping), 19/20 (USB D−/D+),
35–37 (OPI PSRAM), 38 (RGB-светодиод на плате), 43/44 (консоль UART). GPIO 22–27 и 32 на
гребёнку не выведены.

**Модуль PCM5102A «GY».** Запаять перемычки H1L (FLT → normal latency), H2L (DEMP → выкл) и
H4L (FMT → I²S). **H3L не паять**, а XSMT вывести на GPIO 39: прошивка снимает мьют, когда
тактовый сигнал I²S уже стабилен. Пин SCK модуля соединить с GND (мастер-клок не нужен).
VIN питать от 5 В.

**Подсветка TFT.** Пин LED должен управляться (GPIO 2, ШИМ). Если он висит в воздухе, экран
остаётся почти чёрным и выглядит неработающим.

## Сборка

**Arduino IDE → Инструменты:**

| Параметр | Значение |
|---|---|
| Board | ESP32S3 Dev Module |
| Flash Size | 16MB |
| Flash Mode | QIO 80MHz |
| PSRAM | **OPI PSRAM** |
| Partition Scheme | 16M Flash (2MB APP/12.5MB FATFS) |
| USB CDC On Boot | Disabled (консоль на порту UART) |

Ядро ESP32 Arduino **3.3.x** (собрано и проверено на 3.3.12). Прошивка весит около 1.44 МБ.

**Библиотеки:**
[arduino-audio-tools](https://github.com/pschatzmann/arduino-audio-tools),
[arduino-libhelix](https://github.com/pschatzmann/arduino-libhelix),
[LovyanGFX](https://github.com/lovyan03/LovyanGFX),
[U8g2](https://github.com/olikraus/u8g2).

### Настройка

Скопируй `secrets.example.h` в `secrets.h` и заполни:

```cpp
#define WIFI_SSID         "your-ssid"
#define WIFI_PASS         "your-password"
#define DLNA_CONTROL_URL  "http://192.168.1.10:50001/ContentDirectory/control"
#define DLNA_NAME         "My NAS"
```

`DLNA_CONTROL_URL` — адрес управления ContentDirectory сервера. У Synology Audio Station это
`http://<ip-nas>:50001/ContentDirectory/control`. Для других серверов его можно взять из XML
описания устройства (адрес — в заголовке `LOCATION` ответа сервера на SSDP).

Остальные настройки — `#define` в начале `player.cpp`:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `NET_BUFFER_KB` | 256 | сетевой буфер в PSRAM |
| `NET_PREFILL_KB` | 24 | сколько накопить перед стартом трека |
| `TFT_BRIGHTNESS` | 200 | подсветка, 0–255 |
| `VU_REF_DBFS` | −12 | уровень RMS, который стрелочный VU показывает как 0 VU |
| `VOL_MAX_DB` / `VOL_RANGE_DB` | 0 / 60 | шкала громкости: VOL 100 = 0 dB, шаг 0.6 dB |
| `COMP_*` | см. ниже | компрессор |
| `LIM_*` | см. ниже | лимитер |
| `DIAG_LEVELS` | 1 | раз в секунду печатать в консоль диагностику уровня `[LVL]` |
| `RING_*` | см. ниже | кольцо светодиодов |

## Управление

| Орган | Плеер | Браузер |
|---|---|---|
| Поворот энкодера | громкость | листать |
| Клик энкодера | play / pause | открыть папку / играть |
| Двойной клик | повтор трека вкл/выкл | назад |
| Долгое нажатие энкодера | открыть браузер | закрыть браузер |
| PREV | предыдущий трек (после 3 с — трек сначала) | назад |
| PREV долгое | стоп | — |
| NEXT | следующий трек | открыть / играть |
| NEXT долгое | повтор трека вкл/выкл | — |
| PLAY | play / pause | play / pause |
| PLAY долгое | стоп | стоп |
| MODE | следующий экран: карточка → VU-полосы → VU-стрелки → обложка | закрыть браузер |
| MODE долгое | открыть браузер | закрыть браузер |

Браузер начинается с раздела *Library*, в нём два пункта: **SD card** и **DLNA-сервер**. Выбор
трека запускает его и всю остальную папку.

### Кольцо светодиодов

| Состояние | Кольцо |
|---|---|
| Играет | полоса громкости на светодиодах 1–15 (VOL 100 = все 15) |
| Пауза или громкость 0 | только красный 16-й |
| Стоп | один светодиод на уровне громкости |
| Браузер | один светодиод — позиция в списке |

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `RING_ENABLE` | 1 | включить или выключить кольцо |
| `RING_ADDR` | 0x20 | адрес MCP23017 на I²C |
| `RING_CATH_BIT` / `RING_ANODE_BIT` | 4 / 0 | первый бит порта A для 4 катодов / 4 анодов |
| `RING_TEST` | 0 | 1 = при старте зажечь все 16 по очереди и напечатать их номера в матрице |
| `RING_ORDER` | 0…15 | номер в матрице для каждой позиции по кругу (заполняется по тесту) |
| `RING_REVERSE` | 0 | 1 = полоса идёт в обратную сторону |

Кольцо мультиплексируется по одному катоду, по 2 мс (125 кадров в секунду), отдельной задачей.
Если вести его из `loop()`, оно мерцает, пока на TFT уходит кадр.

## Звуковой тракт

```
SD / DLNA ─► MP3-декодер (Helix) ─► громкость (dB, плавно) ─► компрессор ─► лимитер ─► I²S ─► PCM5102A
                                                                                     └─► VU-индикаторы
```

Компрессор и лимитер стоят **после** громкости: их пороги — это уровни на входе ЦАП. На тихой
громкости они ничего не трогают, а на громкой не дают выходу перегружаться.

**Компрессор** (`compressor.h`), ручки как у Cockos ReaComp. По умолчанию это ReaComp в режиме
лимитера:

| Параметр | По умолчанию |
|---|---|
| `COMP_THRESH_DB` | −9 dB |
| `COMP_RATIO` | 0 (= ∞:1) |
| `COMP_KNEE_DB` | 0 |
| `COMP_ATTACK_MS` / `COMP_RELEASE_MS` | 3 / 150 мс |
| `COMP_AUTO_RELEASE` | 0 |
| `COMP_RMS_MS` | 5 мс (0 = пиковый детектор) |
| `COMP_PRECOMP_MS` | 0 (упреждение) |
| `COMP_MAKEUP_DB` | 0 |

Auto release сделан по распространённой схеме с двумя огибающими (release зависит от материала).
Алгоритм самого ReaComp закрыт, поэтому поведение близкое, но не идентичное.

**Лимитер** (`limiter.h`), ручки как у Cockos ReaLimit. Всё, что выше `LIM_THRESH_DB`,
лимитируется, затем весь сигнал сдвигается на `LIM_CEIL_DB − LIM_THRESH_DB`, так что пики на
выходе равны потолку. По умолчанию −1.5 / −1.5 dBFS, упреждение 3 мс (= атака), release 120 мс.
Сэмплы на выходе никогда не превышают потолок, а сигнал ниже порога проходит без изменений.

Красная метка **LIM** в статус-баре TFT горит, пока любая из ступеней ослабляет больше чем на
0.5 dB. При `DIAG_LEVELS 1` консоль раз в секунду печатает:

```
[LVL] VOL 100 (0.0 dB)  peak  -6.1 dBFS  comp  -3.2 dB  limiter   0.0 dB  clipped 0
```

## Архитектура

- **Core 0, `audioTask`:** владеет `AudioPlayer`. Все команды воспроизведения приходят через
  очередь, так что к плееру обращается только одна задача.
- **Core 0, `netfill`:** читает HTTP-поток в кольцевой буфер в PSRAM.
- **Core 1, `loop()`:** кнопки, энкодер, оба дисплея, браузер файлов и DLNA, загрузка и
  декодирование обложек, NVS.
- **Core 1, `ring`:** мультиплексирует кольцо по I²C. `Wire` в Arduino держит мьютекс на каждую
  транзакцию, поэтому кольцо и OLED спокойно делят шину.

## Если что-то не так

| Симптом | Причина / решение |
|---|---|
| TFT тёмный, еле светится | не управляется подсветка, она должна быть на GPIO 2 |
| Неправильные цвета (золото синее) | панель BGR: `cfg.rgb_order = true` (уже выставлено) |
| Помехи на TFT, пропадают, если коснуться проводов | длинные провода: снизить `freq_write` (стоит 16 МГц) или поставить 33–47 Ом последовательно в SCK |
| WiFi зависает или `AUTH_FAIL` при верном пароле | кончилась **внутренняя** RAM. Большие буферы должны быть в PSRAM; смотри строки `[MEM]` при загрузке |
| Случайные перезагрузки, `Cache error`, ошибки кучи во время стрима | слабое питание: WiFi даёт броски тока. Нужен надёжный источник 5 В и 470–1000 мкФ возле платы |
| ЦАП молчит | XSMT в нуле, SCK не на GND или плохо пропаяно гнездо на модуле |
| `[SD] FAILED` | проводка отдельной шины SD (40/41/42, CS 5) или карта не в FAT32 |
| `[RING] MCP23017 not found` | A0/A1/A2 не на GND, RESET не на 3.3 В или нет питания модуля |
| Тест кольца идёт, а светодиоды не горят | перепутаны аноды и катоды: поменяй местами `RING_CATH_BIT` и `RING_ANODE_BIT` |

## Ограничения

- Только MP3 (декодеры AAC и FLAC в AudioTools есть, но пока не подключены).
- До 256 элементов в папке или контейнере DLNA.
- Шрифты покрывают латиницу, Latin-1 и кириллицу; другие алфавиты отображаются пропусками.
- Обложки в формате progressive JPEG декодер не поддерживает.
